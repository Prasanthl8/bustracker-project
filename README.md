# 🚌 Smart Bus Tracking System

A real-time bus tracking web application built solo, supporting 3 live routes with role-based access for admins and passengers.

## 📌 Features
- Real-time GPS bus position updates via Supabase
- Role-based access — separate views for admin and passenger
- Automated email notifications on route changes using EmailJS
- Expandable architecture — easily add more routes
- Tested with real users within 2–3 days of development

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Backend/DB:** Supabase (real-time database)
- **Email Service:** EmailJS
- **API:** RESTful API logic for live bus position updates
